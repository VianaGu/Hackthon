# Hackthon

> Projeto desenvolvido em apenas uma semana para a faculdade.  

## 📌 Sobre o projeto
Este projeto nasceu em uma maratona de uma semana como parte de um desafio acadêmico. Ele representa esforço, criatividade e aprendizado intenso em um curto espaço de tempo.

**Por que é especial?**
- Desenvolvido com foco em praticidade e entrega rápida.
- Ideal para treinar como planejar, executar e entregar um produto funcional em tempos apertados.
- Excelente demonstração de capacidade de adaptação e solução de problemas sob pressão.

## 🚀 Como usar (ou executar)

1. Clone o repositório:
   ```bash
   git clone https://github.com/VianaGu/Hackthon.git
   ```
2. Acesse o diretório:
   ```bash
   cd Hackthon
   ```
3. Abra o arquivo principal no seu editor ou navegador (ex: `homePage/index.html).
